# 사용 방법

## 화면별 올바른 자세 등록

설정 · 카메라의 **올바른 자세 등록**을 열고 화면을 추가하세요. 화면을 드래그해 실제 배치처럼 놓은 뒤, 등록할 화면을 클릭하세요. 좌·우에 화면이 하나씩 있어야 하는 것은 아니며 같은 쪽에 여러 화면을 배치할 수 있습니다.

평소처럼 앉아 몸통 방향을 유지하고 선택한 화면을 바라보세요. 어깨를 편하게 펴고 등록 버튼을 누릅니다. 4초 준비 후 8~10초간 유지하면 저장됩니다. 사용하는 화면마다 등록하세요. 앱은 현재 머리 방향에 가까운 화면의 기준을 골라 그 기준과 현재 자세를 비교합니다.

실패하면 설정 화면과 팝업에 사유가 표시됩니다. 얼굴과 양쪽 어깨 윗부분의 관절점이 화면 안에 보이는지 확인하고 다시 등록하세요. 팔이나 엉덩이 전체가 보일 필요는 없지만 화면 밖의 어깨 점은 사용하지 않습니다. 같은 화면을 다시 등록하면 그 화면의 기준만 바뀝니다. 화면을 삭제하면 연결된 기준 자세도 함께 삭제됩니다. 카메라 위치나 해상도가 바뀌면 다시 등록하세요.

## 감지와 알림 설정

**확인할 자세와 습관**에서 필요한 항목을 켭니다. 상체 구부정·어깨 말림, 머리 전방 이동, 고개 숙임·젖힘, 한쪽 기울임, 어깨 비대칭을 확인할 수 있습니다. 얼굴 만지기는 별도로 기록하며 실제 접촉을 확정하는 기능은 아닙니다.

**자세 감지 민감도**는 기본 / 민감 중 선택합니다. 민감은 더 작은 변화에도 반응합니다. 과하게 반응하면 기본을 선택하세요. 이 설정은 얼굴 만지기에는 영향을 주지 않으며 선택한 값은 저장됩니다.

처음 확인 주기는 2초, 같은 잘못된 자세를 유지했을 때 알림까지의 시간은 20초입니다. 둘은 독립적인 설정입니다. 알림 시간은 10초, 20초, 1분, 2분, 5분, 10분, 20분 중 선택합니다. 잘못된 자세가 확정된 뒤부터 시간을 측정합니다.

미리보기 위 상태 카드에서 판정과 이유를 확인하세요. **감지가 맞는지 테스트**에서 자세를 선택하고 **10초 테스트 시작**을 누르면 판정을 점검할 수 있습니다. 이 테스트는 일반 실행에서 사진을 저장하지 않습니다.

한 사람이 보이면 측정합니다. 여러 사람이 나타나면 기존 사용자를 따르며, 사람이 겹치거나 새 사람이 앞에 오면 잠시 보류합니다. 필요한 특징점이 가려지면 정상으로 처리하지 않고 판정을 보류합니다.

자세 알림은 연결된 모든 모니터 상단에 나타납니다. 알림이 떠 있는 동안 더 자주 확인하며, 바른 자세로 돌아오면 자동으로 닫힙니다. 소리는 기본으로 꺼져 있으며 설정에서 켤 수 있습니다.

## 자세 기록

오늘·주간·월간 자세 점수를 확인합니다. 점수 카드에 마우스를 올리면 클릭 가능한 표시가 나타나며, 클릭하면 해당 기간의 자세별 지속 시간 등 상세 기록을 볼 수 있습니다.

주간 카드의 하루 그래프를 클릭하면 그날의 상세 기록이, 월간 카드의 주별 그래프를 클릭하면 해당 주의 상세 기록이 열립니다. 얼굴 만지기는 자세 점수와 별도로 기록합니다.

## 맞춤 알림

**알림 추가**에서 특정 시각 또는 반복 간격을 설정하세요. 물 마시기 2시간, 스트레칭 1시간 예시는 처음에 꺼져 있습니다. 필요한 알림의 스위치를 켜면 동작합니다. 알림마다 소리를 켜거나 끌 수 있으며 기본은 소리 꺼짐입니다.

## 창 닫기와 종료

창의 X를 누르면 트레이로 숨겨지고 카메라 분석과 알림은 계속 동작합니다. 트레이에서 다시 열거나 일시정지·종료할 수 있습니다. 카메라 스위치를 끄면 카메라를 해제합니다. 프로그램을 완전히 종료한 동안에는 맞춤 알림도 울리지 않습니다.

상단 **사용 안내**를 누르면 단계별 안내를 다시 볼 수 있습니다. 이미 자세를 등록했다면 재등록 없이 다음 단계로 넘어갈 수 있습니다.
