# Posture Track

Windows 웹캠으로 자세 변화를 감지하고, 자세 기록과 맞춤 알림을 제공하는 데스크톱 앱입니다. 영상 분석은 컴퓨터 안에서 수행합니다.

## 주요 기능

- 상체 구부정·어깨 말림, 머리 전방 이동, 고개 숙임·기울임, 어깨 비대칭 감지
- 어깨 윗부분의 관절점을 활용하는 상체 분석과 기본 / 민감 선택
- 화면 배치와 모니터별 올바른 자세 등록
- 오늘·주간·월간 자세 점수와 자세별 지속 시간 상세 기록
- 손가락만 보이는 경우도 포함한 손·얼굴 근접 감지
- 정해진 시각 또는 반복 간격의 맞춤 알림
- 연결된 모든 모니터에 알림 표시, 자세 복귀 시 자동 닫힘
- 카메라 영상의 90°·180°·270° 방향 보정과 여러 사람 등장 시 측정 보호
- 창을 닫아도 트레이에서 실행 유지

웹캠의 2D 특징점과 모델의 추정값을 활용합니다. 조명, 가림, 카메라 위치에 따라 판정이 달라질 수 있으며 의료 진단용 프로그램은 아닙니다.

## Windows 설치 파일

`dist/installer/PostureTrack-Setup-1.0.0.exe`를 실행하면 Python 설치 없이 사용할 수 있습니다. 모델도 포함되어 설치와 실행에 인터넷 연결이 필요하지 않습니다.

- **Windows 로그인 시 자동 실행**은 처음 설치 시 기본으로 선택되어 있습니다. 로그인하면 트레이에서 실행되며, 트레이 메뉴에서 창을 열거나 종료할 수 있습니다.
- 자동 실행 여부를 바꾸려면 같은 설치 파일을 다시 실행하고 해당 옵션을 켜거나 끄세요. 재설치 시 이전 선택을 기억합니다.
- 현재 Windows 사용자에게 설치하며 관리자 권한이 필요하지 않습니다. 기본 경로는 `%LOCALAPPDATA%\Programs\PostureTrack`입니다.
- 시작 메뉴와 바탕 화면 바로가기를 제공합니다. 바탕 화면 바로가기는 설치 옵션에서 선택할 수 있습니다.
- Windows의 설치된 앱 목록에서 제거하면 자동 실행 등록도 삭제됩니다. 설정·기준 자세·기록은 `%LOCALAPPDATA%\PostureTrack\data`에 보존됩니다.
- 소스로 실행하던 `.data/local` 기록을 이어 쓰려면 앱을 종료하고 그 폴더의 내용을 위 `data` 폴더에 복사하세요.

설치 파일을 직접 빌드하는 방법은 [빌드 안내](docs/INSTALLER.md)를 참고하세요.

## 소스로 설치와 실행

Windows x64와 Tkinter가 포함된 Python 3.13에서 확인했습니다. 프로젝트를 내려받은 뒤 PowerShell에서 실행하세요.

```powershell
git clone https://github.com/jdkim93/posture-track.git
cd posture-track
.\setup.ps1
.\start.ps1
```

`setup.ps1`은 가상환경을 만들고 고정된 의존성과 Google MediaPipe 모델을 내려받습니다. 모델 파일은 저장소에 포함하지 않습니다. 초기 설치에는 인터넷 연결이 필요하며, 앱 실행 중에는 모델을 자동으로 내려받지 않습니다.

스크립트 실행이 제한된 환경에서는 아래 명령으로 설치할 수 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe tools/prepare_models.py
.\.venv\Scripts\python.exe -m posture_track
```

카메라 없이 화면을 살펴보려면 `start.ps1 -Demo`를 사용하세요.

## 처음 사용하기

1. **설정 · 카메라 → 올바른 자세 등록**을 엽니다.
2. 사용하는 화면을 추가하고 실제 배치처럼 드래그합니다.
3. 화면을 하나 선택하고, 평소 앉는 몸통 방향을 유지하면서 그 화면을 바라봅니다.
4. 등록 버튼을 누른 뒤 4초 준비 시간을 거쳐 8~10초 동안 바른 자세를 유지합니다.
5. 다른 화면도 각각 등록합니다. 실패하면 표시된 사유를 확인하고 다시 시도하세요.

자세를 등록한 뒤 설정에서 감지할 항목과 민감도를 선택하세요. 상단 **사용 안내**에서 단계별 설명을 다시 볼 수 있습니다. 자세한 설명은 [사용 방법](docs/USER_GUIDE.md)을 참고하세요.

## 개인정보와 데이터

- 일반 실행에서는 사진·영상을 저장하지 않습니다. 테스트 사진 저장은 명시적인 개발용 옵션을 켰을 때만 동작하며 기본으로 꺼져 있습니다.
- 설정·기준 자세·숫자 기록은 소스 실행에서는 프로젝트 폴더의 `.data/local`, 설치 버전에서는 `%LOCALAPPDATA%\PostureTrack\data`에 저장됩니다. Git에는 포함하지 않습니다.
- Python 네트워크 연결은 앱 실행 시 차단합니다. 네이티브 라이브러리의 모든 연결까지 차단하는 OS 방화벽을 대체하지는 않습니다.
- 프로그램을 완전히 종료하면 카메라 분석과 맞춤 알림이 멈춥니다.

## 개발 및 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe -m posture_track --demo --ui-smoke --data-dir .data/ui-smoke
.\.venv\Scripts\python.exe tools/verify_models.py
```

자동 테스트는 계산과 상태 처리의 회귀 검증입니다. 실제 카메라에서의 감지 정확도를 보증하지 않습니다.

저장소에는 앱 소스, 아이콘, 의존성 목록, 설치·실행 도구, 테스트와 사용자 문서를 포함합니다. 개인 기록·테스트 사진·가상환경·다운로드한 모델·타 프로젝트 참고 소스는 제외합니다.
